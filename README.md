# Tetrisk

Tetris where every move and rotation swaps your piece for another one. Dropping doesn't.

**Play:** https://thevangelist.github.io/tetrisk/

Single static `index.html`, no build. SRS rotation, guideline keys, stats in `localStorage`.
Design tokens and component rules: [DESIGN.md](DESIGN.md).
